# LOGIN_PAGE
This is a simple login page app built using Flutter that includes a login form with username and password fields. Upon successful login, the user is navigated to a basic chat screen where messages can be typed and displayed in a list format.

This project demonstrates how to create a user authentication interface (without real authentication for now) and navigate between screens. It includes basic UI components like text fields, buttons, icons, and gradients, making it a good foundation for building more complex applications.

Features
Login Screen:

Username and password input fields
Custom login button with rounded corners
Option for "Forgot Password" (functionality can be added)
Social login buttons (icons for Google and Facebook)
Stylish gradient background
Chat Screen:

Displays a list of chat messages
Text field to type and send new messages
Send button to add the message to the list
